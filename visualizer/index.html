Mathematical Formulations & Methodology (35% Design Validity)

Rigorous analytical framework for measuring validator transaction ordering rules.

1. Spearman's Rank Correlation Coefficient (ρ)

Measures the monotonic relationship between transaction slot index and Compute Unit price:

ρ = 1 - [6 · ∑ d_i²] / [n · (n² - 1)]

Where d_i = rank(-position_i) - rank(cu_price_i). A value of +1.0 represents a strictly descending priority fee order from slot start to slot end.

2. Pairwise Inversion Ratio

Quantifies the proportion of transaction pairs that violate priority ordering:

Inversion Ratio = [ ∑_{i < j} 1(priority_i < priority_j) ] / [ n(n - 1) / 2 ]

An inversion occurs whenever a lower-priority transaction is scheduled before a higher-priority transaction. In Firedancer, this approaches 0.0, while in multi-threaded Agave, interleaving generates an expected ~10-15% ratio across independent accounts.

3. Write-Lock Graph Partitioning

Separates parallel thread execution noise from true scheduling policy:

G = (V, E), where (tx_a, tx_b) ∈ E ⟺ Writable(tx_a) ∩ Writable(tx_b) ≠ ∅

By evaluating Spearman ρ within each connected component of G independently, we isolate the validator's actual priority scheduling rules without penalizing for parallel concurrency speedups.
